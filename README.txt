ENERGY CONVERTER – PWA

Dateien gemeinsam auf einen HTTPS-Webserver laden.
Für GitHub Pages:
1. Neues Repository erstellen.
2. index.html, manifest.webmanifest, sw.js und icon.svg hochladen.
3. Settings > Pages > Deploy from a branch > main / root.
4. Die veröffentlichte Seite in Chrome auf Android öffnen.
5. Chrome-Menü > App installieren / Zum Startbildschirm hinzufügen.

Nach dem ersten vollständigen Laden kann die App dank Service Worker offline verwendet werden.
